Building VMT19937
=================

VMT19937 requires a C++20 compiler and CMake 3.20+.

Jump matrices
-------------
The dat/ matrices live in the remote branch "jumpfiles". They have been restored and uncompressed in the dat/ folder.
If you need to fetch them again:
    git checkout origin/jumpfiles -- dat/
    # Then extract .7z files if needed, or sync from a known good source.

Universal Build Instructions
----------------------------
The project uses a standard CMake build system. On all platforms, the basic commands are:

    cmake -B build
    cmake --build build

### Linux / Remote Linux (Ubuntu/Debian)
1.  Open a terminal.
2.  Run:
        cmake -B build
        cmake --build build -j$(nproc)

### Cygwin
1.  Open a Cygwin terminal.
2.  Run:
        cmake -B build
        cmake --build build -j3

### Windows (MSVC)
1.  Open the "x64 Native Tools Command Prompt for VS 2022" (or run `vcvars64.bat`).
2.  Run:
        cmake -B build
        cmake --build build --config Release

CMake Options
-------------
You can customize the build using `-DVAR=VALUE`:

  NBITS        SIMD width: 128 (SSE4.2) / 256 (AVX2) / 512 (AVX-512).  Default: 128
  MKLROOT      Path to Intel MKL root. Set empty to disable.
  TESTU01_DIR  Path to TestU01 install. Default: empty (disabled).
